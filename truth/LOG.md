## Prompts that worked
- **Checking scroll animation without guessing:** script the browser to scroll in 1% steps and read each layer's transform; any step where a value goes back is a reverse. Screenshots alone missed it.
- **Remove a logo/badge:** send the painting itself as the reference: "Edit this image: remove the oval emblem ... fill that spot with the same ... Keep everything else exactly identical." Worked first time; asking for it in a fresh generation did not.
- **Long panoramas:** Nano Banana 2.1 at `--aspect_ratio 4:1`, "a very wide flat side-on panorama, like a theatre backdrop"; paint background and foreground as separate images ("Layer 2, foreground only, on plain white paper with nothing behind") for parallax.
- **Don't ask a model to split one painting into layers** ("same map without the washes"): it repaints the whole thing. Paint the layers separately or draw one of them in code.
- **Scene set in one style:** a fixed style prefix ("Match the exact painting style of the reference image: ... lots of plain white paper around the subject, edges fading softly into the paper, no text") + `New subject: ...`, with the locked taxi as the only reference. Six different scenes came back matching.
- **Use a photo for the car's shape?** Don't send it as an image (the model may hand the photo back). Describe the shape in words, keep only the style image as reference. Text: `art/style-test/prompt-3.txt`.
- **Keep a style, change the subject:** send the liked image as reference and start the prompt with "Match the exact painting style of the reference image: ...", then describe the new subject. Full text: `art/style-test/prompt-2.txt`.
