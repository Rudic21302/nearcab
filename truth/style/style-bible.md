# Style bible

> Status: style locked 2026-11-07. Model: Nano Banana Pro.

## In one line
A hand-painted storybook taxi company: loose watercolour and ink on warm white paper, carrying a calm, corporate SaaS page.

## Rules
- Page background is paper white; colour comes from the paintings, not from big colour blocks.
- Paintings: loose watercolour washes, visible paper grain, thin slightly wobbly ink outline, soft bleeding edges, lots of white space around each object.
- Framing: flat, front-on or side-on, symmetric where possible (storybook feel). No 3D perspective tricks.
- Objects are isolated cut-outs on white, so code can move them.
- One taxi design, reused everywhere (side view + front view).
- UI (buttons, cards, form) stays clean and flat; at most a faint wash behind a card.
- Influences: the general mood of hand-made storybook films. Never copy a film's characters, frames, typefaces or logos.

## Image prompt prefix (used on every image)
