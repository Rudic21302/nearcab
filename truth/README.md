# NearCab truth

Everything about NearCab, a one-page waitlist site for a taxi dispatch product that does not exist, and the working memory for every Claude session on it. Open this folder as an Obsidian vault, or read it as plain Markdown.

Working on the project? Start at [[CLAUDE]]. It lists the task log, the decisions and the prompts.
